# Portfolio 2026
Personal portfolio website by Rikkert, built with HTML, CSS and JavaScript.

## About this project
This website was created to showcase my experience, education and projects as a Software Developer. Visitors can find more information about my technical skills, development experience and completed projects.

## Languages used
- HTML5
- CSS3
- JavaScript

## Features
- Modern and responsive portfolio layout
- Overview of education and experience
- Projects page
- Contact options via email, GitHub and Discord
- Live clock on the homepage

## Goal
The goal of this project is to demonstrate my knowledge and skills as a software developer and provide a central place where visitors can discover more about my work.
